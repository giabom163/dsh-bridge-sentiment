# 舆情监测分析平台 · v0.05 初版

两个**完全独立**的本机应用，各自一个进程、一个端口、一套界面：

| 应用 | 端口 | 启动 | 内容 |
|---|---|---|---|
| **舆情观察台** | **8790** | `python -B server.py --limit 3` | 品牌栏 + 总览大屏 / 话题分析 / 舆情检索 / 观察清单 / 数据管理（真实产品库 148 条） |
| **任务流水线** | **8791** | `python -B taskboard.py --port 8791` | 7 个桥 store 的 44 个任务只读汇总 + 详情 |

两者互不引用：观察台**不再**提供 `/tasks` 或 `/api/tasks`；流水线**不读**产品库、不碰 `sentiment.db`。

## 快速开始

```bash
cd <repo>
python -B server.py --limit 3          # 打开 http://127.0.0.1:8790/
python -B taskboard.py --port 8791     # 打开 http://127.0.0.1:8791/
```

桌面快捷方式：`舆情观察台.lnk`、`任务流水线.lnk`（点一下即起服务并开浏览器；已在运行则直接打开）。

## 任务流水线的 store 清单

默认内置 7 个（`_p0/_s1/_s3/_s4/_s5/_e2e/bridge`），可用环境变量覆盖：

```powershell
$env:SENTIMENT_TASK_STORES = '[{"key":"_s1","label":"S1","path":"D:\\...\\_s1\\store"}]'
```

## 已知边界

- 8790 的端口是常量（`server.py` 里 `PORT`），改端口需改常量或加参数；
- 流水线页的详情仅只读展示，不提供接收/打回按钮（写操作仍在桥 CLI 与 8766 工程控制台）；
- 本轮未做真实浏览器截图比对，视觉以 HTTP + 源码为准。
